# Middle-Ground Network MN

The **Middle-Ground Network MN** is a grassroots initiative connecting Minnesota communities through dialogue, collaboration, and local action. Our mission is to foster inclusive, community-led projects and scalable local nodes while maintaining transparency and security online.

## Repository Purpose

This repository hosts the website framework, assets, and resources for the Middle-Ground Network MN. It is designed to be **sturdy and scalable**, allowing new local nodes to be added easily as the network grows.

## Getting Started

1. Clone the repository:
2. 2. Edit `index.html` or node pages in `nodes/` to update content.  
3. Add images or PDFs to `assets/`.  
4. Push changes to GitHub. Pages will automatically update.

## Adding a Local Node

1. Create a new folder under `nodes/` (e.g., `nodes/node-rochester/`).  
2. Add an `index.html` for that node.  
3. Update navigation on the main site if needed.
